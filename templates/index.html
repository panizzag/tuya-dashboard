Credenciales de Tuya

Conéctate a tu proyecto en Tuya IoT Cloud Platform para buscar y visualizar tus sensores.

¿Dónde encuentro estas credenciales?

  1. Inicia sesión en Tuya IoT Platform
  2. Crea un proyecto en Cloud -> Development -> Create Cloud Project
  3. Vincula tu cuenta de app SmartLife o Tuya (Devices -> Link Tuya App Account)
  4. Copia el Access ID (Client ID) y Access Secret (Client Secret) de la vista general del proyecto
